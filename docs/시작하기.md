# 스윙워치 설치하기 — 한 줄 붙여 넣고, 화면이 시키는 것만 하세요

Mac에서 **터미널에 명령 한 줄**만 붙여 넣으면 나머지는 설치 도우미가 알아서 합니다.
코드를 받고, 빌드하고, 서명하고, iPhone과 Apple Watch에 설치하는 것까지 모두요.
사람 손이 꼭 필요한 순간(로그인, iPhone·워치 화면의 버튼)에만 **👉 직접 해주세요** 안내가 뜨고,
그 일을 마치면 도우미가 **알아서 알아차리고** 다음으로 넘어갑니다.

처음엔 30~60분쯤 걸려요. 대부분은 **기다리는 시간**입니다(Xcode 구성요소 내려받기, 첫 빌드).

## 준비물

- Mac + **Xcode** (App Store에서 설치만 해두면 돼요 ✅)
- iPhone + 충전 케이블(Mac에 꽂을 수 있는 것)
- Apple Watch (iPhone과 짝지어져 있어야 해요. 없어도 iPhone만 설치할 수 있어요)
- 평소 쓰는 Apple ID — **무료**로 충분해요(개발자 프로그램 결제 불필요)
- Mac 저장 공간 30GB 이상 여유, 인터넷 연결

> 카메라로 스윙을 봐야 해서 **진짜 iPhone**에 설치합니다. Mac 안의 가상 iPhone(시뮬레이터)에는 카메라가 없어요.

## 1. 터미널 열기

키보드에서 **⌘ command + 스페이스바** → `터미널` 입력 → **Enter**.
검은(또는 흰) 창이 열리면 됩니다.

## 2. 아래 한 줄을 복사해서 붙여 넣고 Enter

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/seun1217/swingwatch/main/Scripts/install.sh)"
```

(복사: 위 상자를 드래그해서 ⌘C, 터미널에 붙여 넣기: ⌘V)

## 3. 화면 안내 따라가기

도우미가 단계마다 번호를 붙여 진행 상황을 보여줘요. 중간에 이런 일을 부탁할 거예요. **미리 읽어두면 훨씬 수월해요.**

| 언제 | 해야 할 일 | 어디서 |
|---|---|---|
| 처음 한 번 | Xcode에 **Apple ID로 로그인** — Xcode 메뉴 [Xcode] → [Settings…] → [Accounts] (Xcode 27은 [Apple Accounts]) → 왼쪽 아래 [+] → Apple ID | Mac (Xcode가 자동으로 열려요) |
| 필요할 때만 | **Mac 로그인 암호** 입력 (Xcode 라이선스 동의). 입력해도 화면에 아무것도 안 보이는 게 정상이에요 | 터미널 |
| 처음 한 번 | iPhone을 케이블로 연결 → **"이 컴퓨터를 신뢰하겠습니까?" → [신뢰]** | iPhone |
| 처음 한 번 | iPhone **개발자 모드 켜기**: [설정] → [개인정보 보호 및 보안] → 맨 아래 [개발자 모드] → 재시동 → [켜기] | iPhone |
| 처음 한 번 | 워치 **[신뢰]**, 워치 **개발자 모드 켜기**: 워치 [설정] → [개인정보 보호 및 보안] → [개발자 모드] (iPhone과 따로 켜야 해요) | Apple Watch |
| 빌드 중 | "codesign이 키체인에 접근하려고 합니다" 창 → **Mac 암호 입력 → [항상 허용]** | Mac |
| 설치 직후 | **개발자 신뢰**: iPhone [설정] → [일반] → [VPN 및 기기 관리] → 내 Apple ID → [신뢰] | iPhone |

- 워치가 없거나 나중에 하고 싶으면, 워치 단계에서 **`s` 입력 후 Enter** → iPhone만 설치해요.
- 도우미가 기다리는 중일 때 **Enter**를 치면 바로 다시 확인해요.
- 언제든 **control + C** 로 멈출 수 있고, 같은 명령을 다시 실행하면 이어서 진행해요.

마지막에 **🎉 설치 끝!** 이 보이면 성공이에요.

## 4. 연습장에서 쓰기

1. iPhone을 삼각대 등에 **세로로** 세우고, **정면에서 2~4m**. 머리부터 발끝까지 화면에 들어와야 해요.
2. iPhone에서 **[세션 시작]** (워치에서 시작해도 돼요).
3. **워치에서도 스윙워치 앱을 한 번 열어두세요.** 그러면 손목을 내려도 한 시간 동안 진동이 와요.
4. 평소처럼 치면 스윙이 끝날 때마다 워치가 진동하고 점수·코칭이 떠요.
   어드레스에서 **0.5초쯤 멈췄다가** 치면 인식이 잘 돼요.
5. 끝나면 **[세션 종료]**. iPhone 왼쪽 아래 시계 아이콘에서 기록과 영상을 볼 수 있어요.

## 7일마다 한 번

무료 Apple ID로 설치한 앱은 **7일 뒤 열리지 않아요**(Apple 정책이에요). 그때 **같은 한 줄을 다시 실행**하면 돼요.
두 번째부터는 로그인·개발자 모드 같은 단계가 대부분 이미 끝나 있어 금방 끝나요.

## 문제가 생기면

도우미는 알려진 문제를 알아보고 해결 방법을 한국어로 알려줘요. 그래도 막히면:

- **기록 파일**을 개발 도우미(Claude)에게 보내주세요: `~/SwingWatch/.install/install.log`
  (Finder에서 ⌘⇧G → `~/SwingWatch/.install` 입력. `.`으로 시작하는 폴더라 평소엔 숨겨져 있어요)
  기록에는 기기 이름·기기 ID·서명 팀 ID가 들어 있어요. 공개된 곳에는 올리지 마세요.

| 증상 | 해결 |
|---|---|
| "Xcode 구성요소를 받지 못했어요" | 회사·학교 Wi-Fi나 VPN에서 막힐 수 있어요. 집 인터넷에서 다시 실행하거나, Xcode → [Settings…] → [Components] 에서 iOS·watchOS 옆 [Get] |
| iPhone이 계속 "기다리는 중" | 케이블을 다시 꽂고 iPhone 잠금을 푼 상태로 두세요. [신뢰] 창이 안 보이면 다른 케이블/포트로 |
| 워치를 못 찾음 | 워치를 충전기에 올려 화면을 깨워두고, Mac의 Wi-Fi·블루투스를 켜세요. Xcode 메뉴 [Window] → [Devices and Simulators] 에서 워치를 한 번 클릭하면 연결이 시작돼요 |
| 워치 설치가 계속 실패 | iPhone [설정] → [Bluetooth]를 잠시 끄면 워치가 Wi-Fi로 연결돼요(설치 후 다시 켜기). 안 되면 워치 단계를 `s`로 건너뛰고 나중에 다시 실행 |
| "무료 Apple ID는 7일 동안 앱 ID를 10개까지" | 며칠 뒤 다시 실행하세요. 다음부터는 같은 ID를 재사용해요 |
| "설치할 수 있는 앱 수(3개)를 넘었어요" | 예전에 Xcode로 설치한 다른 개발용 앱을 iPhone(또는 워치)에서 지운 뒤 다시 실행 |
| 7일 뒤 앱이 안 열림 | 정상이에요. 한 줄 명령을 다시 실행하세요 |

## 부록: Xcode에서 직접 설치하기 (도우미를 쓰지 않을 때)

1. `~/SwingWatch/SwingWatch.xcodeproj` 를 더블클릭해 엽니다. (도우미를 한 번도 안 돌렸다면 [저장소](https://github.com/seun1217/swingwatch)에서 `Code` → `Download ZIP`으로 받으세요)
2. Xcode → [Settings…] → [Accounts] 에서 Apple ID 로그인.
3. 왼쪽 맨 위 파란 `SwingWatch` → TARGETS의 **`SwingWatch`와 `SwingWatchWatch` 둘 다** [Signing & Capabilities] → Team에 본인 이름 (Personal Team).
   - "이미 사용 중인 앱 ID"라고 나오면: 같은 화면 위쪽 PROJECT `SwingWatch` → [Build Settings] → 검색창에 `BUNDLE_ID_PREFIX` → 값을 `com.내영문이름` 처럼 바꾸세요(한 곳만 바꾸면 iPhone·워치 앱이 함께 바뀌어요).
4. 위쪽 가운데에서 `SwingWatch` 스킴과 내 iPhone을 고르고 ▶︎.
5. 워치 앱: 스킴을 `SwingWatchWatch`, 대상을 내 워치로 바꾸고 ▶︎ (워치 개발자 모드 필요).
