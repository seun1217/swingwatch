# 스윙워치 시작하기 — Xcode 처음 쓰는 분을 위한 안내

Xcode를 한 번도 안 써봤어도 따라 할 수 있게 만든 문서입니다. 순서대로만 하면 됩니다.
전체 30~50분 정도 걸리고, 대부분은 **기다리는 시간**입니다.

## 준비물

- Mac (Xcode 설치 완료 ✅)
- iPhone + 충전/데이터 케이블
- Apple Watch (iPhone과 페어링되어 있어야 함)
- Apple ID (평소 쓰던 것. **개발자 프로그램 결제 불필요** — 무료로 됩니다)

> **왜 iPhone 실물이 필요한가요?** 이 앱은 카메라로 스윙을 봅니다. Mac 안의 가상 iPhone(시뮬레이터)에는 카메라가 없어서 앱이 켜져도 화면이 까맣습니다. 꼭 진짜 iPhone에 설치해야 합니다.

---

## 1단계 — Xcode 첫 실행 (5~15분)

1. `응용 프로그램` 폴더에서 **Xcode**를 엽니다. (Launchpad에서 "Xcode" 검색해도 됩니다)
2. 처음 열면 **라이선스 동의** 창이 뜹니다 → `Agree` 클릭 → Mac 비밀번호 입력.
3. **"Install additional required components"** 같은 창이 뜨면 `Install` 클릭. 몇 분 걸립니다.
4. 다 되면 "Welcome to Xcode" 창이 뜹니다. **일단 그대로 두세요.**

### Xcode 버전 확인 (중요)

메뉴 막대에서 **Xcode → About Xcode**를 눌러 버전을 확인하고 적어두세요.
(2026년 8월 기준 최신은 **26.6**입니다. 26.x면 그대로 진행하시면 됩니다.)

---

## 2단계 — 코드 내려받기 (2분)

터미널 명령 없이 받는 방법입니다.

1. 사파리에서 아래 주소를 엽니다:
   **https://github.com/seun1217/swingwatch/tree/claude/golf-swing-analysis-app-ef0cdr**
2. 초록색 **`Code`** 버튼 클릭 → **`Download ZIP`** 클릭.
3. `다운로드` 폴더에 받아진 ZIP 파일을 **더블클릭**해서 압축을 풉니다.
4. 생긴 폴더(`swingwatch-claude-golf-swing-analysis-app-ef0cdr`)를 **`서류` 폴더로 옮겨두세요.** (이름은 `swingwatch`로 바꿔도 됩니다)

> 폴더를 `다운로드`에 두면 macOS 보안 설정 때문에 가끔 빌드가 막힙니다. `서류`나 `데스크탑`이 안전합니다.

---

## 3단계 — 프로젝트 열기 (1분)

1. 방금 그 폴더를 엽니다.
2. **`SwingWatch.xcodeproj`** 파일을 **더블클릭**합니다.
   - 아이콘이 파란색 설계도(blueprint) 모양입니다.
   - 비슷한 이름의 다른 파일들(`project.yml` 등)은 건드리지 마세요.
3. Xcode가 열리면서 왼쪽에 파일 목록이 나옵니다.

> 화면 위쪽에 **"Indexing..."** 진행 막대가 도는데, 코드를 읽어들이는 중입니다. 1~3분 기다리면 사라집니다. 그 동안 다음 단계를 해도 됩니다.

---

## 4단계 — Apple ID 등록 (3분)

앱을 내 iPhone에 넣으려면 Apple이 "이 사람이 만든 앱이 맞다"고 서명해줘야 합니다. 무료 계정으로 됩니다.

1. 메뉴에서 **Xcode → Settings…** (단축키 `⌘ ,`)
2. 위쪽 탭에서 **Accounts** 선택.
3. 왼쪽 아래 **`+`** 버튼 → **Apple ID** 선택 → `Continue`.
4. 평소 쓰는 Apple ID와 비밀번호로 로그인 (2단계 인증 코드도 입력).
5. 목록에 내 Apple ID가 뜨고 팀 이름이 **`(Personal Team)`**으로 보이면 성공입니다.
6. 설정 창을 닫습니다.

---

## 5단계 — 서명 설정 (5분) ⚠️ 가장 중요한 단계

여기서 **타깃 두 개 모두** 설정해야 합니다. 하나만 하면 워치 앱이 설치되지 않습니다.

1. 왼쪽 파일 목록 **맨 위**의 파란 아이콘 **`SwingWatch`** 를 클릭합니다.
2. 가운데 화면 왼쪽에 **TARGETS** 목록이 보입니다:
   - `SwingWatch` ← iPhone 앱
   - `SwingWatchWatch` ← Apple Watch 앱
   - `SwingWatchTests` ← 테스트 (건드릴 필요 없음)

### 5-1. iPhone 앱 서명

3. **`SwingWatch`** 를 클릭 → 위쪽 탭에서 **`Signing & Capabilities`** 선택.
4. **`Automatically manage signing`** 체크박스가 **켜져 있는지** 확인 (안 켜져 있으면 체크).
5. **`Team`** 드롭다운을 눌러 **본인 이름 (Personal Team)** 을 선택합니다.
6. 잠시 후 아래에 빨간 에러가 사라지고 `Signing Certificate: Apple Development` 가 뜨면 성공입니다.

### 5-2. 워치 앱 서명 (빠뜨리기 쉬움!)

7. TARGETS에서 **`SwingWatchWatch`** 를 클릭 → 역시 **`Signing & Capabilities`** 탭.
8. 똑같이 **`Team`** 에 본인 이름 (Personal Team) 선택.

### 만약 빨간 에러가 남아 있다면

> **"Failed to register bundle identifier"** 또는 **"The app identifier ... is not available"**
>
> 다른 사람이 이미 쓰고 있는 ID라는 뜻입니다. 아래 **세 곳을 모두** 바꿔야 합니다. 하나라도 빠뜨리면 워치 앱이 조용히 설치 안 됩니다.
>
> | 어디서 | 무엇을 | 예시 (본인만의 문자열로) |
> |---|---|---|
> | `SwingWatch` 타깃 → Signing & Capabilities → Bundle Identifier | iPhone 앱 ID | `com.내영문이름.swingwatch` |
> | `SwingWatchWatch` 타깃 → Signing & Capabilities → Bundle Identifier | 워치 앱 ID | `com.내영문이름.swingwatch.watchkitapp` ← **반드시 위 ID + `.watchkitapp`** |
> | 왼쪽 파일 목록 `SwingWatchWatch` → `Info.plist` → `WKCompanionAppBundleIdentifier` 항목 | 짝이 되는 iPhone 앱 ID | `com.내영문이름.swingwatch` ← **iPhone 앱 ID와 정확히 같게** |
>
> `Info.plist`를 여는 방법: 왼쪽 목록에서 `SwingWatchWatch` 폴더를 펼치고 `Info.plist` 클릭 → 표에서 `WKCompanionAppBundleIdentifier` 행의 값을 더블클릭해 수정.

---

## 6단계 — iPhone 준비 (5분)

1. **케이블로 iPhone을 Mac에 연결**합니다. (무선도 되지만 첫 설치는 케이블이 훨씬 안정적입니다)
2. iPhone에 **"이 컴퓨터를 신뢰하시겠습니까?"** 가 뜨면 **신뢰** → 잠금 해제 암호 입력.
3. **개발자 모드 켜기** (iOS 16 이상 필수):
   - iPhone에서 **설정 → 개인정보 보호 및 보안** 으로 들어갑니다.
   - 맨 아래 **개발자 모드** 를 켭니다.
   - *항목이 안 보이면?* → Xcode에 한 번 연결한 뒤 iPhone을 재시동하면 나타납니다.
   - iPhone이 재시동되고, 켜진 뒤 **"개발자 모드를 켜겠습니까?"** → **켜기** → 암호 입력.

---

## 7단계 — 빌드해서 iPhone에 설치 (첫 빌드 5~15분)

1. Xcode 창 **맨 위 가운데**를 보면 `SwingWatch > iPhone 16 Pro` 같은 표시가 있습니다.
   이게 **"어떤 앱을, 어디에 설치할지"** 를 고르는 곳입니다.
2. 왼쪽 부분이 **`SwingWatch`** 인지 확인 (아니면 클릭해서 SwingWatch 선택).
3. 오른쪽 부분(기기 이름)을 클릭 → 목록에서 **본인 iPhone 이름** 을 선택합니다.
   - 이름 옆에 아무 표시 없어야 정상입니다. (`Simulator` 아래 있는 건 가짜 기기이니 고르지 마세요)
4. 왼쪽 위 **▶︎ (재생) 버튼** 을 누릅니다. (단축키 `⌘ R`)
5. **첫 빌드는 오래 걸립니다.** 상단에 `Building...` → `Installing...` → `Running` 순으로 바뀝니다. 커피 한 잔 하고 오세요.
6. 중간에 Mac 비밀번호를 묻는 **"codesign이 키체인에 접근하려 합니다"** 창이 뜨면 → **항상 허용** 을 누르세요. (한 번만 누르면 됩니다)

### 여기서 "설치는 됐는데 앱이 안 열려요"

iPhone 화면에 **"신뢰하지 않는 개발자"** 경고가 뜨는 게 정상입니다:

1. iPhone에서 **설정 → 일반 → VPN 및 기기 관리** 로 갑니다.
2. **개발자 앱** 아래 본인 Apple ID를 탭합니다.
3. **"...을(를) 신뢰함"** → **신뢰** 를 누릅니다.
4. 이제 홈 화면에서 **스윙워치** 앱이 열립니다.

앱이 열리면 **카메라 권한 허용** 을 눌러주세요.

---

## 8단계 — Apple Watch에 워치 앱 설치 (5~10분)

iPhone 앱만 잘 설치되면 워치 앱은 보통 **자동으로 따라 들어갑니다.**

1. Apple Watch를 손목에 차고 (또는 충전기에 올려두고) iPhone 근처에 둡니다.
2. 5~10분 정도 기다립니다. 워치 홈 화면에 **스윙워치** 아이콘이 생기면 끝입니다.

### 자동 설치가 안 되면

1. iPhone에서 **Watch 앱** (Apple Watch 아이콘)을 엽니다.
2. **나의 시계** 탭 → 아래로 스크롤 → **사용 가능한 앱** 목록에서 **스윙워치** 옆 **설치** 를 누릅니다.

### 그래도 안 보이면 — Xcode에서 직접 설치

1. Xcode 상단 가운데에서 왼쪽 부분을 클릭 → **`SwingWatchWatch`** 선택.
2. 오른쪽 기기 부분을 클릭 → **본인 Apple Watch** 선택.
3. **▶︎** 를 누릅니다. (워치는 무선 설치라 3~10분 걸리고, 화면이 꺼지면 느려집니다 — 손목을 들고 있거나 화면을 자주 깨워주세요)
4. 설치가 끝나면 워치에서 스윙워치 앱을 한 번 열어보세요.

---

## 9단계 — 연습장에서 실제로 써보기

1. iPhone을 **삼각대나 카트에 세로로** 세웁니다.
2. **정면(내 몸 옆쪽에서 얼굴을 보는 방향), 2~4m** 거리. 화면에 **머리부터 발끝까지** 다 들어와야 합니다.
3. iPhone 화면에서 초록색 **`세션 시작`** 을 누릅니다. (또는 워치에서 `세션 시작`)
4. 몸에 파란 뼈대(스켈레톤) 선이 그려지면 인식이 잘 되고 있다는 뜻입니다.
5. 평소처럼 치세요. **스윙이 하나 끝날 때마다** 워치가 진동하면서 점수와 코칭 한 줄이 뜹니다.
6. 끝나면 **`세션 종료`**. iPhone의 시계 아이콘(왼쪽 아래)에서 스윙별 기록과 영상을 볼 수 있습니다.

> **팁**: 세션을 시작할 때 **워치에서 스윙워치 앱을 열어두세요.** 그러면 "백그라운드 유지"가 자동으로 켜져서(기본값 켜짐) 그 뒤로는 손목을 내려도 진동이 옵니다. 한 번에 최대 1시간이라, 더 길게 치실 때는 앱을 한 번 다시 열면 됩니다.

## 자주 나는 문제

| 증상 | 원인과 해결 |
|---|---|
| **7일 뒤 앱이 안 켜짐** | 무료 Apple ID의 정상 동작입니다. Xcode에서 ▶︎ 를 다시 누르면 또 7일 연장됩니다. |
| 빌드 실패: `Signing for "..." requires a development team` | 5단계에서 **타깃 두 개 모두** Team을 선택했는지 확인하세요. |
| 빌드 실패: `Failed to register bundle identifier` | 5단계 아래의 **표 3줄**대로 번들 ID 세 곳을 모두 바꾸세요. |
| 설치 실패: `watchOS apps must be embedded in ... PlugIns` | 아주 옛날 Xcode용 프로젝트를 쓰고 있는 경우입니다. 저장소의 최신 코드를 다시 받으세요(이미 Xcode 26용으로 맞춰져 있습니다). |
| iPhone이 기기 목록에 안 뜸 | 케이블 연결 → iPhone 잠금 해제 → "신뢰" 누름 → 6단계의 개발자 모드 켜기. |
| 앱은 켜지는데 화면이 까맣다 | 시뮬레이터에 설치한 경우입니다. 반드시 실물 iPhone을 선택하세요. |
| 스켈레톤 선이 안 그려짐 | 너무 멀거나(4m 초과), 전신이 안 들어왔거나, 너무 어두운 경우입니다. |
| 스윙을 못 잡아냄 | 어드레스에서 **0.5초 정도 정지**했다가 치면 인식이 잘 됩니다. 감도는 `SwingWatch/Analysis/SwingTuning.swift`에서 조절할 수 있습니다. |
| 워치에 아무것도 안 옴 | iPhone 앱이 **화면에 떠 있어야** 합니다(카메라 촬영 중이어야 하므로). 그리고 워치 앱을 한 번 열어두세요. |

## 코드를 조금 고쳐보고 싶다면

가장 재미있게 바꿀 수 있는 곳들입니다. Xcode 왼쪽 파일 목록에서 찾아 열고, 숫자만 바꾼 뒤 ▶︎ 를 다시 누르면 됩니다.

- **`SwingWatch/Analysis/SwingTuning.swift`** — 스윙 감지 민감도 (잘 못 잡거나 헛스윙까지 잡을 때)
- **`SwingWatch/Analysis/FeedbackEngine.swift`** — 점수 기준과 코칭 문구 (한국어 메시지를 원하는 말투로)
- **`SwingWatch/Analysis/SwingAnalyzer.swift`** — 지표 계산 방식

> 참고: `project.yml`을 고치면 GitHub Actions가 `SwingWatch.xcodeproj`를 자동으로 다시 만들어 커밋합니다. 파일을 추가/삭제하지 않는 한 신경 쓸 필요 없습니다.
